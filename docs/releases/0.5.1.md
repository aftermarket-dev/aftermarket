Aftermarket 0.5.1 fixes two things in AfterHook.

- **An event sent after a restart is now the same bytes as one sent at once.** Events waiting in the state file were sent with the state file's indentation. The signature still checked out, but a receiver comparing two copies of one event saw different bodies. Found while checking the 0.5.0 binary against the example receiver, with a regression test.
- **A state file with a queued event missing its body is refused** with the usual message to move it aside, instead of sending an empty POST.

Recorded results are in `test/results`. The full format is in `docs/hook.md`.

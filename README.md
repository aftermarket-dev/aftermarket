# Aftermarket

Tools that repair, adapt, test and preserve software you can't change.

Aftermarket is one program, `aftermarket`, with a subcommand per tool. The first tool, **AfterPatch**, is a small reverse proxy that fixes HTTP traffic with YAML rules you can read: rename a JSON field, add a header, move a path. It has a dry-run mode and logs every change it makes.

**Status:** in development. Nothing has been released yet. The plan is on [aftermarket.dev/roadmap](https://aftermarket.dev/roadmap/).
